Rob Vagin, brand designer and art director. Tools I built for my own work, free and open source:

- **GONE**, a macOS player for preparing a DJ set
- **PSP Engine**, a native PSP engine for a PS2 game
- **Browser tools** for generative graphics, motion and 3D charts: one HTML file each, no install, works offline

Built with Claude Code.
